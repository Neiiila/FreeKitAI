How to use the word counter

  1. Type or paste text into the box. All counts update as you type.
  2. Use Clean up to fix spacing, for example after copying from a PDF or website.
  3. Use Change case for headings or text typed with Caps Lock on.
  4. Writing for a platform or an assignment? Choose it under Check against a limit, or set a custom word or character limit, and watch the bar as you type.
  5. Made a mistake? Undo last change restores the text from before the last button you used.
  6. Select Copy text and paste the result where you need it.

What each cleaning option does

  • Remove extra spaces: turns runs of spaces and tabs into one space, trims each line, and removes spaces before punctuation. Line breaks stay.
  • Normalize line breaks: makes Windows and Mac line endings the same, removes trailing spaces, and allows at most one blank line between paragraphs.
  • Join broken lines: rejoins sentences that were split across lines (common when copying from PDFs), and keeps blank lines between paragraphs.
  • Title Case: capitalizes main words and keeps short words like “and” or “of” in lower case. Acronyms such as “NASA” are kept.

Common uses

  • Checking an essay or cover letter against a word limit.
  • Keeping a meta description or social post under a character limit.
  • Estimating how long a speech or video script will take to read aloud.
  • Cleaning up text pasted from a PDF before editing it.

Limitations

  • Word counts can differ slightly between tools. For example, some count “e-mail” or “2,500” differently. If a limit is strict, check with the tool your school or publisher uses.
  • Sentence detection uses punctuation, so lists and headings without full stops may not be counted as sentences.
  • Title Case follows general rules; style guides (AP, Chicago, APA) differ in the details.

Frequently asked questions

Is my text uploaded or saved?

No. The counting and cleaning run in JavaScript on your device. The text is not sent to a server and is not saved, so it is gone when you close or reload the page.

Are spaces counted as characters?

Both numbers are shown: “Characters” includes spaces and line breaks, and “Characters without spaces” excludes all whitespace.

How is reading time calculated?

The word count divided by about 238 words per minute, a widely cited average for adults silently reading non-fiction. Real reading speed varies a lot from person to person.

Why does a platform count my text differently?

Each platform has its own counting rules. Some count links as a fixed length, and some count certain emoji or symbols as two characters. This tool counts characters the way people see them, so expect small differences near a limit.

Does it work with languages other than English?

Character counts work for any language. Word counts use your browser's built-in word detection, which supports many languages, but the site itself is in English.
